# Larpidia Photography Studio

Pracovní fotografický archiv. **Nemění atlas ani World Bible.** Polohy míst v atlasu jsou `proposed`, pokud není uvedeno jinak.

Struktura:

- `photos/` — vygenerované snímky `LAR_PH_###`
- `prompts/` — přesné anglické prompty
- `references/` — mapové a prostorové vodítka (ne finální vzhled)
- `metadata/` — lokalita, pohled, validace
- `contact_sheets/` — přehled kolekce

Stav kanonu: atlas 1.0-draft. Fotografie používají schválenou existenci prvků a navržené geometrie; nevydávají návrh za schválení týmem.
